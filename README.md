# Restaurant System - Assembly Project

## 📌 Overview
This is a simple CLI-based Restaurant Management System developed using Assembly Language (EMU8086).

## 🍔 Features
- Customer name input
- Food and drinks menu
- Quantity selection
- Automatic bill calculation
- Final bill display

## ⚙️ How it works
- User enters customer name
- Selects food or drinks
- Chooses item and quantity
- System calculates total bill
- Displays final invoice

## 💻 Technologies Used
- Assembly Language
- EMU8086 Emulator
